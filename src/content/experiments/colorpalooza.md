Color _is_ a construct.

RGB is how computers see it, and RYB is how creatives do. Both are subjective, and contain different perspectives of the same idea, and prior to this project I had never thought about the fact that color _is infact_ subject to who (or what) is experiencing it.

This started as curiosity about historical color spaces and turned into something that genuinely changed how I think about color. We built a color cube that allows you to switch between spaces and see how the same value is completely reinterpreted. Some spaces feel vibrant and emotional, while others feel muted but unified.

However, each one has its own logic, its own vibe, and it reminds me of so many other aspects of life.

While Color Palooza is just a rough exploration, we’ve evolved our idea into something much bigger called Paint Palooza, which aims to hone in more on the understanding of the connection and disconnection of color.

In collaboration with [Iris](https://www.iris-fernandez.com) <3.
