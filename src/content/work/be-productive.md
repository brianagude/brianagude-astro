I'd been keeping physical to-do lists for a while, but I kept losing them, or losing track of what I actually needed to do and when I had time to do it. So I built something simple to hold onto it instead.

It's a straightforward to-do tool that uses local storage only right now, built to be easy to open and easy to use without thinking about it. I built it with Next.js and shadcn, mostly vibe coded with Claude Code so I could move fast and iterate without overthinking the build.

I'm using it myself daily, which means I'm watching my own patterns before deciding what it actually needs. I added PostHog to monitor performance and usage, and noticed other people were actually using it too :). I'm super excited to grow it, slowly, and see something that started as a solution to my own problem turn into something useful for other people as well.

Next, I'll be working on adding auth and a database with Supabase, and figuring out the right workflow for that. Once I know more about how it's actually being used, I'll finally do a real UX pass and a design that's more reflective of my style.
